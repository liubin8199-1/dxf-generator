# benchmarks — 识图评测集（v1.17.4 · B 路线）

**为什么需要它**：改识图规则之前必须先有评测集。v1.17.1 用 7 张真实图纸测出严格正确率
**0/7**，而旧口径却报「识别成功 100%」——那是个**假指标**（只统计"有没有输出"，不统计"对不对"）。
**7 张样本调出来的阈值一定是过拟合**，所以目标是先抽 **30~50 张**建集，再动规则。

## 评测口径（**四个都要报，尤其认错率**）

| 口径 | 定义 | 说明 |
|---|---|---|
| 严格正确 `strict` | `inferred == 真值` | 最硬指标 |
| 宽松正确 `loose` | `inferred ∈ family(真值)` 或 `真值 ∈ inferred` | 同族近似 |
| 正确拒识 `refused` | `inferred 为空` **且** 真值 `oov` | 系统坦诚"不知道"，是**合格**行为，不算错 |
| **认错 `wrong`** | `inferred 非空` 且 不 strict 且 不 loose | **核心指标，必须压到 0%** |

> ⚠️ **度量纪律**：报百分比前先问分母是什么。`识别成功 100%` 与 `严格正确 0%` 可以同时成立
> （前者只数"有输出"，后者数"输出对不对"）。改规则时必须同时给出 before/after 的**认错率**。

## 已知基线（v1.17.1 实测，7 张真实图纸）

| 口径 | 结果 |
|---|---|
| 严格正确 | 0 / 7 = 0% |
| 宽松正确 | 1 / 7 = 14% |
| 认错 | **6 / 7 = 86%** ← 最该压到 0 的指标 |

典型错法：`材料表 → 火灾报警图`、`各层平面 → 火灾报警图`、`暖通图 → 节点大样图`。

### 根因（v1.17.1 已用数据确认，改规则前必读）

1. **规则只认自家图层命名**：`TYPE_BY_LAYERS` 匹配的是 `G_WALL`/`G_DOOR` 这套（本技能自己的输出约定），
   真实图纸用 `A建墙`/`IRC灯具` → 图层信号**零命中**。
2. **模板图例污染**：同一家设计院模板的**189 行图例文字出现在全部 7 个文件里**
   （火警/排烟/空调风/总平面/大样…），文字信号被图例主导；且**图名"首层平面图"本身就是模板行**（7/7 都有）
   —— 批量去模板会把正确答案一起删掉，这是结构性矛盾。
3. **图层是"文档级"而非"图纸级"**：AutoCAD 图层在整个 DWG 里定义一次，实测 6 张图各带 120~469 个图层
   且**共享同一套** → 图层名只能判"这是室内设计图纸集"，判不出是平面还是剖面。

### 可判别信号在「版式/几何」而非关键词

- `01 材料表` 模型空间只有 **262~996** 个实体（主体在 Layout1 的 734 个）；
  `03 1F` 模型空间有 **29,361** 个实体 → **实体数量级本身就是强信号**。
- 材料表 = 表格线框；剖面 = 水平构造层 + 引出线；平面 = 闭合墙线 + 轴网。
  需要 `LWPOLYLINE`/`HATCH` 的几何统计（`read()` 已有 `geometry` 字段）。
