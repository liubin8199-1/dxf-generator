# benchmarks — 识图评测集（v1.17.6 · B 路线）

**为什么需要它**：改识图规则之前必须先有评测集。v1.17.1 用 7 张真实图纸测出严格正确率
**0/7**，而旧口径却报「识别成功 100%」——那是个**假指标**（只统计"有没有输出"，不统计"对不对"）。
**7 张样本调出来的阈值一定是过拟合**，所以目标是先抽 **30~50 张**建集，再动规则。

> ⚠️ **2026-09-12 · 样本污染事故（必读）**
> 第一次扩样本时，13 张被当成"真实外部图纸"的桃花源60# 系列，经 DXF 头 `$LASTSAVEDBY`
> 取证后发现**全部是 `ezdxf` 脚本产物**（其中 4 张还内嵌『AI 平面示意草图 · 非施工图』自述文字）。
> 混入后总认错率从 85.7% "改善"到 71.4% —— **那是稀释，不是进步**。
> 故本评测集引入 `provenance` 字段并**强制分组报数**：**认错率只认 `external` 分组**。

## 真值表格式

```json
{
  "version": "1.1",
  "provenance_note": "…（来源分 external / self_generated 两类）",
  "samples": [
    {
      "file": "03 1F.dxf",              // 逻辑名；raw/ 下同名优先
      "type": "平面图",                   // 真值类型
      "family": ["平面图","基础平面图"],    // 可接受的同族（宽松正确用）
      "oov": false,                      // 真值是否落在系统 34 类类型域之外
      "provenance": "external",          // ★ external=真实出图 / self_generated=本机脚本产出
      "provenance_evidence": "LASTSAVEDBY=Administrator，AC1021，212 图层",
      "source": "…\\p_03 1F.dxf",         // raw/ 缺文件时的回落绝对路径
      "notes": "…"
    }
  ]
}
```

### ★ 来源怎么判（`provenance`）

| 信号 | external（真实出图） | self_generated（脚本产出） |
|---|---|---|
| `$LASTSAVEDBY` | 人名（`Administrator`/`妖怪`/`w`…） | **`ezdxf`** |
| 图层数量 | 120 ~ 469（设计院模板） | 8 ~ 17（自定层） |
| 图层命名 | `A建墙` / `IRC灯具` / `0-结构梁` | `AXIS` / `AREA` / `NOTE` / `SEC_*` |
| 内嵌自述 | 无 | 常含『AI 平面示意草图 · 非施工图』 |
| 实体量级 | 数千 ~ 数万 | 数十 ~ 数百 |

> **`$LASTSAVEDBY` 是最可靠的单一信号**：ezdxf 写盘会留下自己的名字，AutoCAD 出图留的是操作用户。
> 光看图层前缀会漏判——`AXIS/WALL/AREA/NOTE` 不含 `G_` 前缀，但它也是脚本产物。

## 评测口径（**五个都要报，尤其认错率与分组**）

| 口径 | 定义 | 说明 |
|---|---|---|
| 严格正确 `strict` | `inferred == 真值` | 最硬指标 |
| 宽松正确 `loose` | `inferred ∈ family(真值)` 或 `真值 ∈ inferred`（**不含严格**） | 同族近似 |
| 正确拒识 `refused` | 系统**弃权** 且 真值 `oov` | 坦诚"不知道"，是**合格**行为，不算错 |
| 空答 `abstain` | 系统**弃权** 但 真值在域内 | 严格说未答对，但严重度低于自信答错 |
| **认错 `wrong`** | **给了答案** 且 不 strict 且 不 loose | **核心指标，必须压到 0%** |

> ⚠️ **度量纪律 #1**：报百分比前先问分母是什么。`识别成功 100%` 与 `严格正确 0%` 可以同时成立
> （前者只数"有输出"，后者数"输出对不对"）。改规则时必须同时给出 before/after 的**认错率**。
> **各桶必须互斥，且 `strict+loose+refused+abstain+errored+wrong == n`**——脚本已内置自洽校验，
> 出现过"宽松把严格重复计进去"（5+6+0+1+0+14=26 ≠ 21）的静默错，故 `loose` 一律排除 `strict`。
>
> ⚠️ **度量纪律 #2（v1.17.6）**：`drawing_reader.read()` 低置信时返回**字面量占位符 `"未识别"`**
> （非空字符串），导致旧口径 `refused` 桶**结构性恒为 0**（"正确拒识 0%"是假数字），
> 且"如实说不知道"与"自信答错"被记成同一种错。现已把占位符视同**弃权**并单列 `abstain`：
> `认错 = 自信答错 + 空答`。
>
> ⚠️ **度量纪律 #3（v1.17.6）**：**自产样本会稀释认错率**。系统认自己画的图必然更准
> （自产组 61.5% vs 外部组 87.5%）。评测集**必须分组报数**，认错率只认 `external`。

## 已知基线

### ① v1.17.1（7 张，全部真实出图）

| 口径 | 结果 |
|---|---|
| 严格正确 | 0 / 7 = 0% |
| 宽松正确 | 1 / 7 = 14% |
| 认错 | **6 / 7 = 86%** |

### ② v1.17.6（21 张，混合 —— 仅供参考，**不是能力证据**）

| 口径 | 结果 |
|---|---|
| 严格正确 | 5 / 21 = 23.8% |
| 宽松正确（非严格） | 1 / 21 = 4.8% |
| 正确拒识 | 0 / 21 = 0% |
| 认错 | **15 / 21 = 71.4%**（自信答错 14 + 空答 1） |

### ③ ★ v1.17.6 校正基线（`--external-only`，8 张真实出图）—— **这才是真实识别能力**

| 口径 | 结果 |
|---|---|
| 严格正确 | **0 / 8 = 0%** |
| 宽松正确（非严格） | 1 / 8 = 12.5% |
| 认错 | **7 / 8 = 87.5%**（自信答错 6 + 空答 1） |

## 根因（改规则前必读）

1. **规则只认自家图层命名**：`TYPE_BY_LAYERS` 匹配的是 `G_WALL`/`G_DOOR` 这套（本技能自己的输出约定）。
   真实图纸用 `A建墙`/`IRC灯具`/`0-结构梁` → 图层信号**零命中**。
2. **模板图例污染**：真实图纸的**189 行图例文字出现在全部 7 个文件里**
   （火警/排烟/空调风/总平面/大样…），文字信号被图例主导；且**图名"首层平面图"本身就是模板行**
   —— 批量去模板会把正确答案一起删掉，这是结构性矛盾。
3. **图层是"文档级"而非"图纸级"**：AutoCAD 图层在整个 DWG 里定义一次，实测 6 张图各带 120~469 个图层
   且**共享同一套** → 图层名只能判"这是室内设计图纸集"，判不出是平面还是剖面。
4. **★ 系统从不弃权（结构性缺陷）**：`read()` 低置信时返回占位符 `"未识别"` 而非空值。
   本批 2 张 OOV 真值**一张都没被拒识**，全部"自信答错"。**拒识率恒为 0** 是认错率的主要上游原因
   —— 一个从不承认自己不知道的系统，认错率不可能压到 0。

### 可判别信号在「版式/几何」而非关键词

- `01 材料表` 模型空间只有 **262~996** 个实体（主体在 Layout1 的 734 个）；
  `03 1F` 模型空间有 **29,361** 个实体 → **实体数量级本身是强信号**。
- 材料表 = 表格线框；剖面 = 水平构造层 + 引出线；平面 = 闭合墙线 + 轴网。
  需要 `LWPOLYLINE`/`HATCH` 的几何统计（`read()` 已有 `geometry` 字段）。

## 边界（对外承诺必须写清）

- 评测集真实样本仅 **8 张**（且 7 张来自**同一家设计院模板**）→ **结论不可外推到所有图纸**。
- 自产样本 13 张**只能验证"改坏没有"，不能证明"识别变准"**。
- 在该批次上"修好"很可能只是"记住了这家模板"，**扩到 30 张真实图纸前不要宣布识别率提升**。
